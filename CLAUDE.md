## ui-evidence
<!-- ui-evidence:claude:begin -->
Use ui-evidence for before/after UI review in this repo.

- If setup looks incomplete, read `ui-evidence/installation.md` and finish the setup.
- For explicit runs, prefer the project command in `.claude/commands/ui-evidence.md`.
- For natural-language requests about UI comparison or screenshots, use `npx ui-evidence` instead of ad hoc browser steps.
- Persist config in `ui-evidence/config.yaml` and hooks in `ui-evidence/hooks/*`.
- Return the final `review/index.html`, `report`, `manifest`, and key comparison image paths.
